# SMART HOMES BUILDERS AND DESIGNERS
### Modern Architectural & Construction Studio Website

Official website for **Smart Homes Builders and Designers**, an architecture and design firm specializing in cost-effective building design, residential homes, luxury villas, commercial spaces, and turnkey construction based in Kodikkunnu, Palakkad District, Kerala.

---

## 🏛️ Brand & Architectural Aesthetic

- **Design Philosophy**: Minimalist, editorial-style architectural layouts with deep charcoal, warm white, light stone grey, and subtle bronze/warm gold accents.
- **Typography**: Display font (*Cinzel*) for elegant architectural headlines paired with clean geometric sans (*Plus Jakarta Sans*) for high legibility.
- **Logo & Watermarking**: Authentic company gold emblem integrated across desktop/mobile sticky navigation and individually watermarked onto every portfolio project.

## 🛠️ Technology Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`)
- **Icons**: Lucide React
- **Routing**: React Router DOM (v7)
- **Deployment**: Vercel

---

## 🚀 Development & Build

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```
